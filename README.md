# Skala Gamtek

**A Simple Technical Drawing Scale Calculator**

Skala Gamtek is a lightweight calculator designed to help users calculate and convert technical drawing scales quickly and accurately. It simplifies the process of determining actual dimensions, drawing dimensions, and scale ratios, making it useful for students, engineers, and anyone working with technical drawings.

## Features

- **Scale Calculation** – Calculate drawing scales based on actual and drawing dimensions.
- **Dimension Conversion** – Convert between actual measurements and scaled drawing measurements.
- **Simple Interface** – Easy-to-use interface with a straightforward calculation workflow.
- **Time-Saving** – Reduce manual calculations and minimize potential calculation errors.
- **Lightweight** – Designed to be simple, fast, and accessible.

## What Is Drawing Scale?

A drawing scale represents the proportional relationship between a measurement on a technical drawing and its corresponding real-world dimension.

For example:

| Scale | Meaning |
|---|---|
| 1:1 | Full size |
| 1:2 | Half size |
| 1:5 | One-fifth of actual size |
| 1:10 | One-tenth of actual size |
| 2:1 | Twice the actual size |

**Basic Formula:**

`Scale = Drawing Dimension / Actual Dimension`

Make sure both dimensions use the same measurement unit before calculating.
